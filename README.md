# hillview-llc

## AMOP -- Alluvial Mining Operations Platform

See [`amop/README.md`](amop/README.md) for the full platform: grade control,
geospatial VAM blend optimization, plant simulation, finance/outreach
pipeline, exploration-through-HSE cost tracking, and a JORC-style prototype
feasibility report, with an MCP server layer, a Streamlit dashboard, and a
one-click Windows installer.

**To run it on Windows:** double-click [`build_windows.bat`](build_windows.bat)
(or the copy inside `amop/`). It installs everything, verifies itself
against 23 golden tests, and launches the app in your browser -- no manual
terminal steps.
